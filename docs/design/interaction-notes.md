# Agent Workbench · 原型交互约定

状态：2026-11-05 用户已确认 HTML 原型 v0.2 满意，视觉与主要交互作为开发基准。正式业务行为见 [产品规范](../specs/workbench-v1.md)，统一状态与事件见 [数据契约](../specs/data-contracts.md)。下表区分原型代码和生产能力；其后各节为交互约定。用户认可设计不等于真实 ACP、文件、网页、终端或原生窗口已经实现。

## 体验范围

本轮先确认一扇好用的工作台：项目与会话切换、输入与输出、辅助面板、设置。正式前端采用 Rust + GPUI / gpui-component；当前 HTML 用于验证布局和交互，不作为正式前端源码。

- Agent 回复、执行过程、审批、模型和连接状态为示例数据与定时模拟，没有连接真实 ACP、Codex 或其他 Agent。
- 文件是原型内的示例文件。编辑与“保存”只作用于原型沙盒，不覆盖磁盘项目源码。图片附件由用户主动选择或粘贴，不自动上传。
- 浏览器首先展示示例页面和导航交互。HTML 无法保证任意网站允许嵌入；地址变化、示例加载不等于真实原生 WebView 已验证。
- macOS 窗口按钮是外观与交互提案，网页不能据此证明系统托盘、原生拖动或窗口生命周期已实现。
- 页面中的任务、文件变化、Issue、用量均为原型样例，不代表当前项目实际数据。
- 生产中的模型、思考强度、权限、图片和运行中补充能力，必须以 Agent 返回能力为准；示例选项不作为兼容性承诺。

原型的产品界面只保留名称、值、必要状态和操作。设计原因、组件来源、模拟范围留在本说明，不做每个区域的介绍文案。

会话内的 Agent/模型/强度/权限选择保存在 `sessions[].config` 并随本地存储保存；设置页“Agent → 配置”的示例启动命令保存在 `agentCommands`。这些都是本地原型数据，并未启动或配置真实 Agent。

“对话字号”通过统一正文变量切换 14/16 px，只改变回复阅读字号，不改变全局界面比例。刷新保留的内容包括样例项目/会话、设置、示例文件及两栏宽度；内容标签、浏览器各页导航历史和演示终端记录已加入本地存储；当前面板展开状态、侧栏折叠状态和部分工具光标/滚动不跨页面刷新保存。页面刷新后原运行计时器也不会恢复。

以下设计表中的外部冲突、真实浏览器、Agent 配置失败/确认等规则，属于正式设计边界，不是 HTML 已实现状态。原型中的本地保存亦不能证明 SQLite、真实文件写入或后台进程恢复已完成。

## 通用状态与动效

控件同时拥有多种状态。`Selected + Hover`、`Selected + Focus` 是合法组合；选中和焦点不能互相覆盖。

| 状态 | 外观与行为 |
| --- | --- |
| Idle / 闲置 | 中性文字、透明或所属表面背景；正常字重，无投影、缩放和装饰描边 |
| Unselected / 未选中 | 可选择集合中的非当前项；基础外观与 Idle 相同，不表示禁用，仍可点击；一组选项已有当前项也不额外压暗其他项 |
| Selected / 选中 | 浅一档背景、主要文字，可配细指示条；多选只用于明确的多选任务，本原型导航和选择器默认单选 |
| Hover / 悬停 | 可操作表面轻微提亮；已选项仍保留选中身份；不放大、不上浮 |
| Focus / 键盘焦点 | 清晰细焦点框；与 Hover、Selected 可叠加；鼠标点击不产生无意义的整页焦点高亮 |
| Pressed / 按下 | 表面略压暗；不位移、不改变文字布局；松开或移出取消按压 |
| Disabled / 禁用 | 降低强调度，停止 Hover/Pressed 和提交；必要原因可通过可达提示或相邻状态读取，不能仅靠颜色解释 |
| Open / 已打开 | 触发器持续有选中/按下表面；关联弹层可见，焦点转入；再次点击同一触发器关闭 |
| Closed / 已关闭 | 清除 Open 表面，弹层退出且不再接受焦点或鼠标；已有选择值保留 |
| Loading / 处理中 | 原控件尺寸与标签位置稳定，局部进度标识；阻止重复提交，保留输入 |
| Error / 失败 | 在失败对象旁说明具体问题并提供重试或修正；不抹去已有内容，不自动重放可能已接受的操作 |

视觉优先级：禁用先决定能否操作；Loading 防重复；Selected/Open 决定持续背景；Pressed/Hover 调整其表面；Focus 独立叠加；错误状态与上述状态共存。关闭的表面不参与命中与焦点。

| 过渡 | 提案 |
| --- | --- |
| Hover、Selected、Pressed | 背景与文字颜色 120 ms，ease-out；焦点框立即出现，避免键盘位置不明 |
| 菜单、下拉框、图片预览 | 开合 140 ms，ease-out；透明度 0 ↔ 1，可有不超过 4 px 的短位移 |
| 左侧栏、辅助面板、放大还原 | 尺寸/透明度 180 ms，ease-out；内容不从头载入 |
| 折叠执行详情 | 高度/透明度 160 ms；保留锚点，避免把正在读的消息推离视口 |
| 页面切换 | 轻微淡入 140 ms；现成内容不制造假 Loading |
| 分界线拖动 | 立即跟随指针，明确不使用缓动；释放后记录尺寸 |
| 流式文本 | 收到内容后及时绘制，不逐字加人为动画、不重复淡入整段；只重排受影响内容 |
| 减少动态效果 | 遵循系统/设置，取消位移与尺寸动画；保留即时状态反馈 |

普通文本更新、光标移动、键盘焦点、拖动尺寸和减少动态效果模式允许即时变化。过渡期间离场表面应及时失去命中能力，不能留下透明按钮。

## 左侧栏与导航

| 控件 | 状态转换、结果和保留内容 |
| --- | --- |
| 侧栏折叠按钮 | Expanded ↔ Collapsed；按钮始终可重新打开；主区获得空间，当前项目与会话不变；焦点留在按钮 |
| 项目行 | Unselected → Selected，其他项目取消选中；下方会话仅显示该项目；切换前保存当前草稿和阅读位置；项目展开箭头与选中操作分开 |
| 项目展开箭头 | Closed ↔ Open；只改变子内容可见性，不意外切换项目；ArrowLeft/Right 支持收起/展开 |
| 会话行 | 点击成为当前会话并恢复该会话草稿/阅读位置；运行、待审批、失败状态独立于 Selected；切走继续模拟运行 |
| 新建会话 | 创建当前项目的空会话，加入列表并选中，焦点进入输入框；空态不塞推荐卡片与介绍段落 |
| 搜索 | Closed → Open → 查询 → 结果/无结果；结果显示必要项目归属；Esc 回原位置；选中结果切换会话后关闭 |
| 设置入口 | 工作台 → 设置页；当前任务继续；返回后恢复工作台上下文，焦点回入口或原控件 |
| 侧栏分界线 | Idle 细线 → Hover 可拖光标 → Dragging 即时尺寸；限制在可用区间；键盘聚焦后方向键调宽，Home 恢复默认；失焦不丢尺寸 |

会话运行状态：Idle → Running → Completed；Running 可进入 AwaitingPermission、Stopping、Failed；审批通过回 Running，拒绝后保留结果；停止后进入 Stopped。它们是任务状态，不替代行的交互状态。侧栏与主区必须对应同一会话，后台更新不能串入当前会话。

## 辅助面板与编辑

| 控件 | 状态转换与行为 |
| --- | --- |
| 工具入口 | Closed → Open(tool)；点击另一个入口变为 Open(other)，复用右侧区域；点击当前入口或收起按钮回 Closed |
| 面板大小 | Docked(width) ↔ Zoomed；Zoomed 只改变布局，关闭后回到对话；还原使用原宽度并按窗口大小夹取 |
| 面板分界线 | 同侧栏拖动状态；保持对话和工具各自的最小可用宽度；窄窗口允许直接放大工具，不挤出整页横向滚动 |
| 面板恢复 | 记住每个工具的选择、展开、筛选和滚动；切换工具不丢编辑草稿、不重置浏览器、不停止 Agent |
| 文件树 | 目录折叠与文件单选分开；选中文件打开编辑器；Loading/不存在/不可读都有就地状态；长路径在尾部截断并可查看完整值 |
| 文件编辑 | Loading → Clean → Dirty → Saving → Clean / SaveError；输入不自动保存；保存成功清除未保存标记；失败保留 Dirty 内容 |
| 外部文件变化 | Clean 时更新；Dirty 时进入 Conflict，保留本地内容，显示查看差异和处理入口；不悄悄覆盖用户编辑 |
| 保存 | Ctrl/Cmd+S；无更改时禁用，保存中禁止重复；原型保存到沙盒，不写磁盘目录；切换/收起不会默默丢弃 Dirty 文本 |
| Git 行与差异 | 文件单选，选中后显示对应差异；未选文件正常显示；差异可滚动；不将原型里的提交动作冒充真实 Git 提交 |
| Issues | 状态筛选单选，文本搜索保留；点击行进入详情，再返回列表时恢复筛选和阅读位置；Loading/空/失败分开 |
| 用量 | 显示会话或项目的明确范围；无数据写“暂无数据”，不能用 0 假装真实测量；样例值在本说明中声明为模拟 |
| 浏览器地址栏 | Idle → Focus → Editing → Navigating → Loaded / Failed；Enter 导航，Esc 取消未提交地址；加载中可停止，失败保留地址并可刷新 |
| 浏览器导航 | 后退/前进在无历史时禁用；刷新不改变地址；浏览器与外部链接打开方式明确区分；放大、收起和切换工具不等于刷新网页 |

关闭辅助面板后，焦点回对应工具按钮；面板有未提交编辑时，收起只是隐藏而非销毁。放大时提供明确还原按钮；Esc 优先关闭顶部弹层，不能一次穿透多个层级。

## 输入区与选择器

输入区状态：Empty ↔ Draft → Submitting → Accepted（清空被接受内容）或 SubmitError（保留内容）。Running 时仍允许 Draft。请求未确认前，不清空草稿与附件，不把“正在提交”显示成“已发送”。

输入自动长高，到上限后内部滚动；对话保持独立滚动。中英文输入法合成期间，Enter 只确认候选词，不发消息。原型默认 Enter 发送、Shift+Enter 换行；设置中的发送方式需与按钮提示一致。

| 控件 | 状态转换与行为 |
| --- | --- |
| Agent 选择器 | 单选；已安装可连接，未安装/需登录的选项有真实下一步入口；切换后重新计算模型与能力；取消不改变当前值 |
| 模型选择器 | Closed → Open → 搜索/键盘移动 → Confirmed；当前项勾选、Hover 和键盘焦点独立；无结果与加载失败不混用；切换模型后无效强度必须重选或回有效默认 |
| 思考强度 | 仅呈现当前模型实际支持的选项；不支持时不显示此控件；当前强度单选，确认后更新 |
| 访问权限 | 显示 Agent 实际确认的值，默认完整访问仅在 Agent 支持时成立；Pending 时防重复，失败回原值并反馈；原型选择仅演示 UI |
| `/` 命令 | 输入触发列表，筛选→高亮→确认；方向键移动，Enter 选中，Esc 关闭后保留文字；命令需要参数时继续在输入框编辑 |
| `@` 文件 | 同命令选择，结果包含文件名及必要路径；确认插入可移除的引用；空结果可继续输入，不能伪造不存在文件 |
| 通用下拉 | 打开定位当前项；长度超出内部滚动；向窗口内侧展开，避免被输入区或面板裁切；确认/取消后焦点回触发器 |
| 图片输入 | 选择/粘贴/拖入 → Processing → Ready / Failed；Ready 显示缩略图，单击预览；每个附件可单独移除，失败可重试 |
| 图片预览 | Closed ↔ Open；Esc 或关闭按钮返回输入区，保持光标；图片只在预览层缩放，不改变输入框宽度 |
| 图片不兼容 | 保留图片并标记原因，发送不可用，允许更换模型或移除；不能悄悄只发送文字 |

选择器当前值变化必须与实际生效值一致。运行中选择的新模型/强度用于下一条任务是本轮设计提案；立即补充继续交给正在执行的 Agent。正式 ACP 接入时以能力和生效确认细化，不能借参考产品假定所有 Agent 行为一致。

## 发送、补充与队列

| 行为 | 状态与结果 |
| --- | --- |
| 普通发送 | 非空且附件 Ready 时可用；Empty/Processing/不兼容时禁用；接受后出现用户消息并开始模拟回复 |
| 立即补充 | 仅 Running 且能力支持时可用；Submitting → Accepted / Failed；已接受补充显示在该轮过程内；失败保留草稿，不静默转为排队 |
| 排队发送 | Draft → Queued；紧贴输入区展示条目；待发送项和已经发送的消息明确区分 |
| 编辑队列 | Queued → Editing → Saved / Cancelled；保存前原项保持；编辑期间保护原草稿，取消恢复；开始发送的条目不能继续覆盖编辑 |
| 删除队列 | 删除指定待发送项，不影响运行任务或其他项；焦点转相邻项或输入框 |
| 自动执行 | 当前轮正常结束且队列未暂停时取下一项；仅移除已被接受的项；失败不把后续项连锁执行 |
| 停止 | Running → Stopping → Stopped；按钮暂不可重复，输出保留；队列转 Held，等待显式继续 |
| 继续队列 | Held → Queued/Running；空队列不显示无效继续按钮；失败条目可编辑或删除 |

快捷键要在原型说明/提示中可查，并与设置一致；按钮保留“立即补充”“排队发送”的可理解操作，不只依赖陌生图标。运行中改变草稿不得改变已排队消息当时选择的配置。

## 对话、流式输出与审批

| 对象 | 状态与行为 |
| --- | --- |
| 回复正文 | Waiting → Streaming → Complete / Stopped / Error；正文按段落、代码、表格展示；已输出内容在中断后保留；复制取当前可见正文 |
| 滚动跟随 | Following → 用户向上滚动 → ReadingHistory；新输出不拉回底部，显示“回到最新”；点击后回 Following；正常滚至底部也恢复跟随 |
| 布局变化 | 面板缩放、代码展开和历史插入保持消息锚点；每会话独立记录位置；选中文本时不抢焦点或清除选区 |
| 工具行 | Pending → Running → Completed / Failed / AwaitingPermission；Running 的动作保持可见；完成后紧凑显示摘要，可展开完整输入输出 |
| 工具详情 | Closed ↔ Open；用户主动打开的详情不在流式更新时自动收起；错误、审批不被完成项折叠规则隐藏 |
| 计划清单 | Pending → Active → Done / Failed；状态由事件驱动；只读项不用可点击复选框误导用户 |
| 权限请求 | AwaitingDecision → Submitting → Allowed / Denied / Error；允许和拒绝同时明确可达；提交中防重复；处理后保留决定结果 |
| Agent 选择题 | 未选 → 单选/多选 → 提交 → 已回答；是否多选由问题定义；未达要求时提交禁用；提交后保留答案，重复提交不可用 |
| 错误恢复 | 就地显示错误和可执行动作；重试只针对明确失败操作；断线后不能把旧回复当作新会话的输出 |

设置提供“紧凑 / 完整”工具显示，两者仅改变呈现，执行记录不删除。紧凑默认，当前动作、错误和审批仍可见；完整显示每次工具调用详情。切换设置时保持当前阅读位置。

## 独立设置页

分类单选，左侧当前分类持久选中，右侧内容替换；页面滚动限于内容区域。返回工作台后恢复原状态。

- 开关：Off ↔ On；单击立即反映选择，键盘 Space 切换，焦点保留；保存失败时恢复并显示具体问题。
- 分段选择：Unselected ↔ Selected；互斥单选；紧凑/完整、发送方式等选项即时生效。
- 下拉设置：使用与输入区相同的选择器约定；打开、取消、确认和键盘行为一致。
- 只读/不可用设置：明确不可操作；不使用正常按钮外观假装可用。
- 恢复默认：只恢复其明确范围的外观或设置，不删除项目、历史和草稿。
- 本地偏好可由原型浏览器保存；这不代表正式 SQLite 持久化和多窗口一致性已经完成。

## 原型体验检查路径

下列为应体验的路径，实际完成情况由主原型交付检查记录给出：

1. 切换项目，再切换会话；确认项目筛选、选中状态、草稿与阅读位置。
2. 折叠侧栏，拖动宽度；打开文件面板，编辑示例文件，保存、放大、还原、收起。
3. 打开浏览器，输入地址，体验示例导航、后退/前进、刷新与失败表现；确认模拟范围。
4. 打开模型与强度选择器，键盘选择，尝试无结果；输入 `/`、`@`，取消后继续写。
5. 粘贴/选择图片，预览与移除；验证输入法确认不会误发送。
6. 发送消息，观察流式输出；上滚后不被拉回，回到最新后继续跟随。
7. 运行中立即补充、排队、编辑和删除队列；切走会话后任务继续，停止后队列暂停。
8. 完成一次允许或拒绝审批；错误和审批在紧凑模式下仍可见。
9. 进入设置，切换紧凑/完整、减少动态效果、发送方式；返回恢复工作台。
10. 980 × 640 与常规窗口检查：主要操作可见、弹层不被裁切、没有整页横向溢出。

## v0.2：结构化结果、内容标签与终端

此节按用户最新确认覆盖先前的“无标签栏/无终端”范围。原型仍是 HTML，终端不运行系统命令。

### 输出层级

- 结论为正文首要层级，结果卡片承载完成内容；代码块有语言/文件标题和复制按钮；文件变更卡片显示文件名、用途与增删数量。
- 使用实心表面与内部留白分组，工具过程收在一条可展开的实心摘要内，取消工具详情的侧边装饰线。
- 文件卡片为打开操作，不是可多选集合。Idle 与 Unselected 相同；Hover 提亮表面和边界，Pressed 加深，Focus 使用统一焦点环。点击建立/激活对应文件标签并打开右侧编辑器。过渡 120ms，不缩放、不上浮。
- 代码复制只复制代码内容，反馈短暂“代码已复制”；结果和正文不会随复制动作改变。

### 顶部已打开内容

| 状态/操作 | 外观与行为 |
| --- | --- |
| Idle / Unselected | 无强调底色，辅助文字，固定图标和关闭位置 |
| Selected | 同一组只有一个当前内容标签；中性浅一档底色和主文字。文件未保存以小圆点额外表示，与选中正交 |
| Hover / Pressed / Focus | 背景依次轻微提亮、加深；键盘焦点环独立保留，120ms 颜色过渡 |
| Disabled | 最后一个会话标签的关闭按钮禁用；其他关闭动作保持可达 |
| 打开 / 切换 | 会话切回对应对话；文件、网页、终端默认在右侧打开。已经放大的辅助区切换内容时保留放大状态；会话标签恢复对话空间 |
| 关闭 | 关闭标签不删除会话，也不停止 Agent。未保存文件询问保存并关闭/不保存/取消。停止终端命令使用终端内停止操作；关闭终端标签保留演示终端记录，重新打开可继续查看 |
| 键盘 / 溢出 | 方向键、Home/End 在当前标签组切换；标签过多时横向滚动，当前项进入可见区。标签关闭后聚焦选中的相邻内容 |

原型以当前项目过滤顶部内容标签；侧栏重新选择已关闭标签的会话会重开该标签。

### 浏览器网页标签

- 浏览器顶部有独立网页标签组和“+”，只控制网页。它和全局内容标签指向同一个网页状态，切换及关闭同步。
- 各网页分别保存地址、前进/后退历史、示例页面待办状态和阅读位置。新标签从空白地址页开始。
- 选中/悬停/焦点遵循顶部标签规则；Loading 只标记对应网页；关闭某页不删除其他网页历史。
- 普通网址仍通过系统浏览器访问；原型不声称已经嵌入真实网站。

### 终端

- 右上角入口打开右侧终端，建立内容标签；终端可新增、清屏、输入命令、放大、还原和收起。
- Idle 显示可输入提示符；Focus 显示输入焦点环；Running 禁用该终端的重复提交，提供停止，标签显示运行标记；完成后恢复输入；未知命令原位显示“原型未模拟这条命令”。
- 支持的演示命令：`pwd`、`ls`/`dir`、`git status`、`cargo check`、`echo`、`clear`/`cls`、`help`。输出全部由原型生成，绝不执行本机 shell。
- 切换文件/网页/设置只隐藏终端，保留其输入和输出；模拟运行可继续完成。新建终端使用独立记录。
