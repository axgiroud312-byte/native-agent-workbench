# Agent Workbench · 产品与验收规范

版本：v0.1 / MVP。状态：需求与原型已对齐，供开发拆分使用。视觉基准：[已确认原型 v0.2](../design/design-board.html)。

## 1. 产品目标

构建 Rust + GPUI 原生桌面 Agent 工作台。用户在项目中创建会话，选择 Agent、模型及权限，发送文本、图片或文件引用，同时运行多个任务，并在同一窗口查看代码、编辑文件、浏览网页和操作终端。

核心体验：窗口整体安静、连续；左侧管理项目与会话，主区域阅读和执行，右侧按需打开辅助工具。内容通过布局、字重、留白和实心表面形成层次，必要的按钮、状态与错误文字直接服务操作。

开发与首轮真机验收以当前 Windows 环境为入口。macOS 风格窗口控件、炭灰哑光、弱顶栏是已确认视觉要求；macOS 发布前独立完成平台验收，平台能力不由 HTML 原型推定。

## 2. 已确认交付范围

| 编号 | 能力 | 完成表现 |
| --- | --- | --- |
| R01 | 原生窗口与侧栏 | 原生 GPUI 主界面；可折叠、可调整侧栏；项目与会话分别排列 |
| R02 | 项目与会话 | 添加、切换、重命名、删除；项目筛选会话；搜索；本地历史持久化 |
| R03 | 内容标签 | 会话、文件、网页、终端有对应标签；切换、关闭、未保存标记和键盘导航 |
| R04 | Agent 接入 | Codex 优先，ACP 统一接入；发现、安装确认、认证、连接与能力检测 |
| R05 | 输入与配置 | 多行输入、模型/强度/权限选择、`/` 命令、`@` 文件、图片粘贴/拖入/选择 |
| R06 | 连续工作 | 流式回复、立即补充、可编辑队列、停止、失败恢复；至少两个会话同时运行 |
| R07 | 有层次的输出 | Markdown、代码块、结果块、文件变更卡片、工具过程、计划、审批和受支持的提问控件 |
| R08 | 文件与 Git | 实际文件阅读/编辑/保存、外部修改处理；Git 状态和只读差异 |
| R09 | 内嵌浏览器 | 本地项目与普通网站；多个网页标签；独立导航历史、加载状态 |
| R10 | 终端 | 真实项目目录下的交互式 shell、输入输出、选择复制粘贴、停止、调整尺寸 |
| R11 | Issues 与用量 | GitHub Issues 查看筛选及加入输入；按 Agent 实际报告显示用量 |
| R12 | 独立设置页 | 当前窗口内独立页面；返回恢复工作台；工具过程紧凑/完整可切换 |
| R13 | 后台与恢复 | 关闭窗口收进托盘，任务继续；明确退出；重启恢复可恢复的本地记录与布局 |

以上是本期正向交付范围。主界面使用 gpui-component；网页内容由独立 WebView 承载，终端由独立 PTY 会话承载，两者均属于原生工作台的辅助区域。

## 3. 视觉和布局基准

### 3.1 窗口与左侧栏（R01）

- 默认窗口 1240 × 800，最小 980 × 640；Token 中数值均为 100% 缩放下的逻辑尺寸。
- 中性炭灰、哑光不透明表面；窗口和工作区连续，主区域占主要空间。
- Sidebar 默认 264，范围 240–320；折叠后留可发现、可键盘操作的展开入口。
- 顶部使用 macOS 风格窗口控件与窗口拖动区。控件点击和内容标签点击不参与拖动。
- 上部项目列表，下部当前项目的会话与状态，底部固定设置。列表分别管理滚动；长列表虚拟化。
- 同级行共享文字、图标、状态与操作对齐线。项目和会话默认行高 36；状态分组按“需要处理、运行中、最近”组织。
- 设置入口和待处理状态不能被长列表推出可操作范围。

### 3.2 顶栏与内容标签（R03）

- 集成顶栏高 48；左侧放当前项目已打开内容标签，右侧为 `+ / 文件 / Git / 浏览器 / 终端 / Issues / 用量`。
- 标签可指向会话、文档、网页或终端；标题被截断时可查看完整名称或路径。
- 顶部标签切换文件/网页/终端时，内容默认在右侧辅助面板展示；对话仍留在主区域。
- 点击会话标签或侧栏会话，恢复对应对话视图并收起辅助面板。已打开内容记录仍保留。
- 放大是辅助区域占满 Sidebar 以外的工作区；不改变应用缩放或操作系统全屏。还原回原来的宽度。
- 多个标签不增加顶栏高度；溢出横向滚动，保证选中项及其关闭按钮可达。方向键、Home/End 在当前标签组内导航。
- 关闭会话标签只关闭视图；会话记录和后台任务继续存在。重新从侧栏打开恢复原会话。
- 关闭未保存文件出现“保存并关闭 / 不保存 / 取消”；关闭网页释放对应 WebView；关闭终端标签隐藏终端，明确“结束终端”才终止进程。
- 标签数据以对象 ID 标识，不能靠标题、当前数组位置或“最后打开的文件”定位。

### 3.3 辅助面板

- 默认收起；一次显示一个工具，复用同一区域。不同文件、网页和终端各有自己的保留状态。
- 默认宽 400，最小 300；正常布局优先给对话至少 380 的可用宽度，必要时钳制辅助宽度。
- 分界线拖动直接跟手；也可键盘调整。打开、收起、放大和还原采用短过渡。
- 切换或隐藏面板不销毁文档缓冲区、正在运行的 shell 或会话任务；焦点移到有效控件。
- 窗口变窄、缩放、内容增长时，滚动条留在区域边缘，输入区始终可见。

## 4. 项目与会话（R02、R06）

1. 添加项目通过本机目录选择；以规范化目录身份识别已有项目，显示用户可读的名称。
2. 项目被选中后，会话区只显示该项目会话。搜索可跨本地项目，结果标出所属项目。
3. 新会话绑定一个项目和一个 Agent，使用项目实际目录。不同会话可以共用目录并同时工作。
4. 会话拥有独立消息、草稿、附件、配置、队列、运行状态、审批、滚动位置和未读状态。
5. 首期至少验证两个会话并行。切走、打开设置、隐藏窗口均不取消后台任务。
6. 同目录的外部变更通过文件观察更新；编辑器用冲突检测保护用户未保存内容。Agent 间的任务分工由用户安排，工作台不伪造隔离目录。
7. 本地历史只索引工作台创建的会话。能否继续外部会话由实际 Agent 恢复能力决定；不支持时保留历史并提供新会话入口。
8. 删除项目指移除工作台记录，不删除磁盘目录；删除会话移除应用记录。涉及运行任务先停止并确认资源释放，删除操作不波及同目录的其他会话。

工程默认：初始同时运行上限设为 2，排队等待名额不占用正在执行状态；该值可作为工作区设置调整。每个会话仍按自己的队列顺序提交。

## 5. Agent、配置和输入（R04、R05）

### 5.1 接入

发现本机已安装 Agent → 读取注册信息与系统兼容性 → 必要时用户确认安装 → 启动适配器 → 协议初始化 → 按返回方法认证 → 新建/恢复会话 → 获取能力、模型和配置选项。

优先集成 Codex 的 ACP 适配器，UI 只读统一业务模型。当前 `codex-acp` 是独立 stdio ACP 适配层，不能把 Codex 可执行文件等同于 ACP 服务。[适配器说明](https://github.com/agentclientprotocol/codex-acp)

### 5.2 选择器

- Agent、模型、思考强度、权限/模式排列在 Composer 底部，显示当前值；模型支持搜索和分组。
- 选项、有效值和可用状态来自 Agent；原型中的模型名字与三档强度是样例。
- 优先使用 ACP `configOptions`；旧模式或扩展能力在 Runtime 适配。模型改变后重新校验强度和其他依赖选项。[ACP 配置说明](https://agentclientprotocol.com/protocol/v1/session-config-options)
- 用户选择值、待应用值、Agent 已确认值分别保存。失败保持实际值并给出局部重试，不能只是改下拉框文字。
- 新会话默认请求“完整访问”；恢复会话沿用用户已保存的选择，不把之前选定的受限权限重新提升。只有 Agent 确认已应用相应模式时才显示生效；Agent 实际不支持或拒绝时显示真实权限，保留后续可选操作。
- 权限执行边界由 Agent 的实际设置管理；应用不把“完整访问”转换成伪造的审批同意。
- 工程决定：当前运行使用已开始时的配置快照；运行中所选新模型/强度/权限用于后续新一轮，当前待审批请求仍按其原始权限语义处理。立即补充仍进入当前运行，不声称切换了当前模型。
- 空闲时允许选择 Agent；已有历史不因更换 Agent 被静默清空。需要新外部会话时明确创建新的应用会话并保留旧会话。

### 5.3 编辑与附件

- 多行输入随内容增长，超过上限后内部滚动。中文输入法选词的 Enter 不发送；Shift+Enter 换行。
- 默认 Enter 发送，支持设置为 Ctrl/⌘+Enter。快捷键解释放在菜单/提示和快捷键页。
- `/` 展示当前 Agent 可用命令和明确标识的工作台命令；`@` 搜索当前项目文件。上下选择、Enter 确认、Esc 收起并返回输入。
- 文件引用带身份和路径；发送前记录是当前文件引用还是附件快照，展示与传输语义一致。
- 图片支持粘贴、拖入、文件选择；缩略图、预览、移除、准备状态和失败重试齐全。上限由应用和实际 Agent 双重校验。
- 不支持图片时保留输入和附件，提供换模型或移除选项。不能把图片默默丢弃后发送文字。
- 草稿按会话保存。提交前保留可恢复副本；本地可靠受理与 Agent 已接收是不同状态，具体见[数据契约](data-contracts.md)。

## 6. 运行、补充和队列（R06）

| 用户动作 | 业务规则 | 界面反馈 |
| --- | --- | --- |
| 空闲时发送 | 为本次提交生成唯一标识并持久记录；按实际配置启动 | Pending、运行、完成或错误分别表示 |
| 运行中排队 | 本地保存顺序、正文、附件、引用和配置快照；当前任务结束后发送 | 队列紧贴 Composer；可编辑、取消 |
| 运行中立即补充 | 能力支持且当前运行可接收时注入；保持当前运行配置 | 按接受结果显示已补充或未送达 |
| 编辑排队消息 | 原条目在保存前仍有效；编辑期间不误覆盖已经发出的条目 | 保存/取消；恢复原草稿 |
| 停止 | 进入 Cancelling，向 Runtime 发取消；等待最终状态与资源回收 | 保留部分输出；队列转暂停 |
| 出错/断连 | 保留本地历史和待提交内容；不自动重发结果未知的请求 | 错误就近显示，提供可确定语义的重试/重新连接 |
| 继续队列 | 用户明确恢复，从未消费的队首继续 | 顺序稳定，每条消息只发一次 |

运行中默认发送方式为排队，Ctrl/⌘ 修饰键使用另一种方式；当默认发送快捷键本身已有修饰键时，用额外 Shift 区分。输入法、命令弹层与文本换行优先于发送快捷键。

当前 Codex 适配器文档提供 `_session/steering` 扩展。必须核对版本与协商能力、处理明确结果；通用 ACP Agent 不能假定都支持。无法证明接受时保留内容，不能通过停止重启或第二次普通 Prompt 假装立即补充。[扩展文档](https://github.com/agentclientprotocol/codex-acp/blob/main/docs/steering.md)

## 7. 输出、滚动与交互内容（R07）

- 正文采用文档排版，结论置前；代码块有语言/文件名、可选择文本和复制；文件卡片显示实际变更信息并打开对应文件/差异。
- 结果块按输出结构渲染。模型的自然语言主张不能自动变成“检查通过”；工具成功、命令退出码、文件增删数必须有对应事件或实际结果来源。
- 当前步骤可见，已完成过程默认收成紧凑摘要。设置中“紧凑 / 完整”立即改变展示，不删除事件数据；审批和错误持续可见。
- 计划由实际计划事件更新；受支持的提问以原生单选、多选、文本等控件展示。未知结构降级为可读内容，不执行任意生成的界面代码。
- 审批绑定请求与所属会话；允许/拒绝后显示提交中，再按结果完成；取消和断连让过期请求失效。
- 用户停留底部时跟随新输出；向上阅读后保持锚点并显示“回到最新”。切换会话分别恢复阅读位置。
- 拉宽面板、字体变化、图片加载、展开工具时，以消息 ID 与局部偏移保持阅读锚点；旧历史向上加载不把用户拉回底部。
- 流式更新只重排受影响内容，保留文本选择和输入焦点；取消时留下部分输出并标出停止状态。正文不逐字做装饰动画。
- 大代码块自身横向滚动；正文自然换行；表格按真实列结构显示；屏幕缩小时不撑宽整个应用。

## 8. 文件、Git、浏览器与终端（R08–R10）

### 8.1 文件

项目文件树支持展开、搜索、打开。编辑器至少提供文字选择、代码高亮、行号、撤销/重做、查找、缩进、保存与未保存标记。

工程决定：普通编辑显式保存；后台保留恢复草稿。未修改缓冲区收到磁盘变化可刷新并保留光标；已修改缓冲区进入冲突状态，提供查看差异、保留编辑另存或重新载入。覆盖保存必须基于用户明确选择。

保存采用文件版本校验和可用的原子替换方式；权限、编码、已删除/移动、二进制或超大文件均有可读反馈。每个文件的光标、选择、滚动与未保存缓冲区按文档 ID 保留。

Git 面板首期展示当前仓库状态、变更文件、增删统计和只读差异；未处于 Git 仓库时给出真实空态。文件卡片与 Git 面板共用文件身份，差异不与另一项目混用。

### 8.2 浏览器

- 真实内嵌本地 HTTP 服务与普通 HTTPS 网站，支持地址栏、后退/前进、刷新/停止、外部打开。
- 浏览器内部网页标签与全局内容标签指向同一个网页对象，同步创建、切换、关闭。
- 每页独立保留导航栈、标题、加载/错误状态；隐藏或放大只调整视图，不重新创建页面。
- 关闭网页才释放对应视图；重启恢复 URL 和标签，不假设网页内存、表单及 JavaScript 执行现场可恢复。
- 登录、Cookie、证书错误等遵循平台 WebView 的真实行为；普通网页不获得工作台内部命令执行桥接。
- 外部打开是补充入口。正式浏览器验收必须证明内嵌页面可用，不能把 HTML 原型的外部跳转当作完成。

### 8.3 终端

- 默认 shell 使用当前平台已安装的用户 shell，工作目录为当前项目；用户操作和 Agent 工具终端采用不同的终端身份。
- 支持真实 PTY 输入输出、ANSI 解析、回滚滚动、文本选择、复制粘贴、Ctrl+C、窗口尺寸变化；每个终端有独立缓冲区和退出状态。
- 新建终端创建独立 shell；标签关闭仅隐藏，重新打开回到原终端。面板提供已有终端列表和明确“结束终端”，显示退出码后允许重开。
- 收起窗口不杀进程；应用真正退出时结束其持有的 shell 及子进程。重启只恢复终端描述/必要历史，原进程不伪装成仍运行。
- 原型的几条演示命令仅用于设计验收。正式终端必须执行用户实际输入，不能用硬编码结果替代。

## 9. Issues、用量与设置（R11、R12）

Issues 首期按 GitHub 仓库读取，支持未完成/已关闭/全部、搜索、详情和加入 Composer。未关联仓库、未认证、离线、无结果分别处理；加入输入是待用户发送的草稿，不自动派发任务。

用量显示当前会话实际得到的 tokens、上下文和可用统计。未知值显示未提供，不能用示例数字、按字符估算或进度动画填充真实用量。费用只在来源可信且有完整计费信息时展示。

设置在当前窗口独立成页，左侧分类：通用、对话与输入、Agent、外观、快捷键。返回恢复会话、草稿、面板、标签、阅读位置；后台继续运行。

首期设置项包括 Agent 启动/认证配置、输出紧凑/完整、底部跟随、发送快捷键、对话字号、减少动效、并发上限。产品固定选择直接显示当前值，不以无效控件装饰页面。高级说明按需展开，日常页面只保留必要标签。

## 10. 生命周期与本地恢复（R13）

- 红色关闭按钮将窗口收进系统托盘/菜单栏入口，任务继续；系统最小化与关闭操作语义区分。
- 托盘可重新打开窗口，并有明确“退出”。有任务、shell 或未保存文件时列出实际影响；选择停止并退出后，先完成保存处理、取消与清理，再退出进程。
- SQLite 保存项目、会话索引、消息、必要事件、队列、设置、布局和附件元数据；原始图片进入应用数据目录，凭据优先由 Agent 自身认证管理。
- 重启恢复工作台记录与布局；正在发送但结果未知的请求保持待核实状态，不自动重放；队列暂停等待恢复。
- Agent 会话运行态恢复只在协议和 Agent 支持时尝试。无法恢复仍可读历史，明确新建后续会话。
- 页面隐藏、辅助标签关闭、设置切换与 Runtime 销毁是不同操作，不能靠视图析构意外停止任务。

## 11. 原型与正式应用的交接

用户认可的是视觉、信息层级和交互方向。当前 HTML 的全局变量、定时器、固定数据、简化 Markdown、共享示例文件以及浏览器本地存储不是生产架构。

| 原型展示 | 正式交付要求 |
| --- | --- |
| 定时输出与固定完成卡片 | 真实 ACP 事件、实际工具结果、消息来源与生命周期 |
| 固定模型、权限选项 | 协商能力、配置确认与兼容性验证 |
| 示例文件与 localStorage | 真实目录、文档版本、冲突保存与 SQLite 元数据 |
| 示例网页/外部打开 | 原生 WebView 内嵌、真实导航与多页生命周期 |
| 硬编码终端结果 | 真实 PTY 与 shell、ANSI 渲染、停止与资源清理 |
| 固定 Git/Issues/用量 | 来自实际仓库、服务和 Agent 的数据 |

控件具体状态见[交互约定](../design/interaction-notes.md)，尺寸和颜色见[设计 Token](../design/design-token.md)。本规范处理业务行为差异；已确认原型不因工程方便而被另一套布局替代。

## 12. 验收场景

| 编号 | 操作 | 必须观察到的结果 |
| --- | --- | --- |
| A01 | 打开原生窗口，调整到 1240×800 和 980×640 | 已确认的布局层级成立；输入、标签、工具入口可达，无全窗横向溢出 |

| A03 | 打开两文件、两网页、两终端并切换标签 | 对象身份稳定；文件内容、网页地址及终端输出分别保留 |
| A04 | 收起侧栏、拉宽/放大/还原辅助区 | 对话阅读位置和编辑状态保留；键盘焦点不落入隐藏区域 |
| A05 | 使用已安装 Codex 完成初始化和认证 | 明确实际适配器/协议版本，真实发送并完成一轮回复 |
| A06 | 切换模型、强度和权限；制造配置拒绝 | 成功值和失败反馈真实；默认完整访问经过 Agent 确认 |
| A07 | 中文输入、`/`、`@`、粘贴与拖入图片 | 选词不误发；弹层键盘可用；图片实际到达支持的 Agent |
| A08 | 两会话同时输出，切走并打开设置 | 任务继续、事件各归其主；未读与待审批在对应会话显示 |
| A09 | 在有能力的运行中补充；排队后编辑/删除 | 补充进入当前任务；队列顺序和配置正确，无重复提交 |
| A10 | 任务结束边缘补充、断连、重启 | 未接收/已接收/结果未知分清；待核实消息不自动重发 |
| A11 | 审批允许/拒绝；审批期间取消 | 结果回到对应请求；过期审批不能继续操作；其他会话不受影响 |
| A12 | 流式期间向上阅读、选择文字、调面板宽度 | 不抢焦点、不强制拉底、不破坏选择；点击回最新后恢复跟随 |
| A13 | 编辑文件时由 Agent/外部进程修改同文件 | 无未保存编辑时刷新；存在编辑时呈现冲突，不静默覆盖 |
| A14 | 查看 Git 差异、Issues，向输入框引用 Issue | 真实来源正确；转入草稿而非自动发送 |
| A15 | 内嵌 localhost 和 HTTPS 页面，切页/缩放/打开弹层 | 页面真实可交互，隐藏页不盖住控件，导航独立 |
| A16 | 终端运行 shell 命令、长输出、Ctrl+C、调整尺寸 | 实际 shell 执行；输出/光标正常；前后台和尺寸事件正确 |
| A17 | 设置紧凑/完整和字号，再返回 | 立即作用于展示，已有消息、草稿和后台运行保留 |
| A18 | 关闭窗口再由托盘打开，之后明确退出/重启 | 隐藏时任务继续；退出资源回收；重启本地记录仍在，运行态不伪造 |
| A19 | 回答受支持的单选、多选或文本提问，提交时重连/过期 | 字段按实际请求校验，回答只进入对应请求；旧表单失效，未知送达不自动重投 |

交付报告分别写清：代码完成、自动检查、真实窗口/真实 Agent 已验证、用户验收。当前用户确认的是 HTML 设计；上述原生与真实服务场景需要开发阶段取得新的证据。
